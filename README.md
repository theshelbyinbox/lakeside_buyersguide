# The Lakeside Motel & RV Park — Sale Website

Buyer-facing storytelling site for The Lakeside Motel & RV Park, Christmas Valley, Oregon.

- `index.html` — the complete homepage (all styles and scripts are inside this one file)
- `assets/` — web-optimized photos and logos

No build step, no dependencies. To publish with GitHub Pages: Settings → Pages → deploy from the `main` branch, root folder. To edit copy, open `index.html` in any text editor — all visible text is plain HTML.
